# GestãoHair

Sistema web de gestão para salão de beleza.

## Funcionalidades

- Cadastro e listagem de clientes.
- Cadastro e controle de produtos e estoque.
- Alerta de estoque baixo.
- Cadastro de agendamentos.
- Bloqueio de conflito de horário por profissional.
- Dashboard com dados integrados ao MySQL.

## Tecnologias

- Java Web e Servlets
- JDBC
- MySQL
- HTML, CSS e JavaScript
- Apache Tomcat
